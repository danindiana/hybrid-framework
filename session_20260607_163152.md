### 2. Streamlining Workspace Extraction
When attempting to index the entire `/home/jeb/programs/gemini_cli_workspace/` directory, we encountered and resolved several issues:
1. **LLM API Key Requirements**: Initial scans picked up hundreds of documentation, PDF, and image files requiring LLM credits. We configured a robust `.graphifyignore` file to ignore non-code files, ensuring a free, fast AST-only extraction.
2. **Subprocess OOMs and Segfaults**: Spawning 32 workers on 38k+ files caused workers to fail due to memory constraints and triggered a C-level stack overflow / segmentation fault (`sig=11`) in `libpython3.13.so` during symbol resolution.
3. **Solution**: We updated `/home/jeb/programs/gemini_cli_workspace/.graphifyignore` to skip the massive `ai-agent-architectures/` subdirectory and limited workers to `4`.
* **Execution Command:**
  ```bash
  /home/jeb/programs/gemini_cli_workspace/session_20260607_163152/graphify/.venv/bin/graphify extract /home/jeb/programs/gemini_cli_workspace/ --max-workers 4
  ```
* **Result:** Successfully extracted 72 primary workspace files, producing **449 nodes, 716 edges, and 68 communities**.
